# Will You Marry Me?

A proposal page where the "No" button runs away from your cursor.

## What it does

- `/` asks the question with a big YES and a NO button.
- Hovering NO sends it to a random position on the page.
- YES goes to `/celebration`, a page of celebratory GIFs and a congratulations message.

## Stack

- React, React Router
- Create React App (`react-scripts`)
- Plain CSS

## Run it locally

```bash
npm install
npm start
```

Opens at http://localhost:3000.
